# goSenoir

Go 即时通信（IM）学习项目。

## 运行

需要 Go 1.27 或更新版本。在项目根目录执行：

```bash
go build -o server .
./server
```

服务监听 `127.0.0.1:8888`。在另一个终端连接：

```bash
nc 127.0.0.1 8888
```

使用 `Ctrl+C` 停止服务，修改代码后需要重新编译。

## 文件

- `main.go`：程序入口。
- `server.go`：TCP 监听、在线用户管理和广播消息入口。
- `user.go`：用户创建及向客户端发送消息。
